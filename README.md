PROJETO ROTA

Guia de ônibus e metrô para regiao metropolitana do recife. O Foco no passageiro o aplicativo ROTA de maneira de intuitiva e limpa disponiabilizar informações sobre linhas e percusos de onibus do recife. 
Quais linhas passam naquela parada?, quanto tempo para linha para chegar na parada?, definir rotas e saber quais onibus pegar e alarmes de proximidade de ônibus.
